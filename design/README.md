# 九曲拾忆设计文档

本目录保存“九曲拾忆”参加第三届开源鸿蒙大赛的作品设计资料：

- `九曲拾忆_作品设计方案.docx`：作品设计方案
- `九曲拾忆-黄河文化分布式数字档案.pptx`：作品设计展示文档

仓库根目录及 `entry/src/main/ets/` 保存项目工程源码；HAP、截图和本地构建缓存不纳入本仓库。

## 使用前的安全替换

源码中的同步服务地址统一使用 `your-sync-server.example.com:8080` 占位符。使用者需要替换为自己的网关地址，并在设备端配置自己的同步令牌；不要把真实令牌、云服务密钥、AI API Key、签名证书或私钥提交到 GitHub。AI 服务建议通过自己的服务端代理调用，客户端只保留接口占位配置。
